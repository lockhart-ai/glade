# P5-01: Right panel tabs, resizing and collapse

The frame for all right-panel tabs.

## Scope

- Tabs: Tool calls, Files, Todos, Artifacts, Subagents, with counts (hidden when zero); ⌘⌥1–5.
- Drag handle on the left edge to resize; width persists per window.
- Collapse button (full shortcut handling in P7-05).

## Acceptance criteria

- [ ] Resizing is smooth and remembered.
