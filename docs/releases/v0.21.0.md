Glade 0.21.0 fixes "needs you" so an unread reply counts even while a task still has subagents or other background
work running — the bug that hid nearly every reply from a busy task — and adds a small purple count to the closed
workspace switcher for tasks that need you in other workspaces. A plugin can now ask Glade to open a task you click
in its view, built for clicking a cat or kitten in Nekomata. The image viewer's title moves above the image itself
and its pager stops at the first and last image instead of wrapping round, and the queue box, the Todos progress
bar and a lead reply before a question card all pick up small visual fixes.

## Needs you

- **"Needs you" now includes any unread reply, even while the task still has subagents or watchers running.** 0.20
  treated a task with background work as working regardless of its reply, which hid nearly every reply from a task
  that keeps subagents running. A read reply with background work still shows as working; a read reply with nothing
  running is idle. (#470)

## Workspace switcher

- **The closed workspace switcher now shows a small purple count** of the tasks that need you in other workspaces,
  hidden at zero and "9+" past nine, with the count given in its tooltip. (#476)

## Plugins

- **A plugin can now ask Glade to open a task when you click in its view** (`openTask`, with an optional subagent
  id): Glade selects the task, switching workspace if needed, and with a subagent opens the Subagents tab on it.
  Built for clicking a cat or kitten in Nekomata, whose own side ships separately. (#471)

## Image viewer

- **The full-size image viewer's title now sits just above the image's own top-left corner**, instead of in the
  window's top-right chip. Stepping through images now stops at the first and last instead of wrapping round, with
  the arrows dimmed there. (#469)

## Queue and input bar

- **Queued messages above the input bar are now lighter rounded chips instead of black rows**, a long one wraps to
  two lines, and the attachment and pasted-text chips in the input bar take the same fill. (#465)

## Todos

- **The Todos tab's progress bar now fills its done part in the teal of the done checkmarks**, on a lighter track.
  (#468)

## Chat

- **The reply just before a question card is now on the purple card** like every other reply. (#467)

## Sidebar

- **The sidebar's Pinned section is no longer shown while nothing is pinned.** (#458)

## Under the hood

- The timing tests now run on their own in CI with budgets measured on the Linux runners; they had been set on a
  Mac and failed about one run in ten after the unit job moved to Linux. (#475)
- CLAUDE.md now has a standing Performance section. (#454)
- Plumbing for a future agent sandbox, which nothing in this release turns on. (#457)

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.21.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.20.1 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- This corrects the supervisor's own rule from 0.20 (#430), which had background work outrank an unread reply. (#470)
- There's no settings switch for a plugin opening a task: Glade detects the click or key press itself, since a
  plugin can't claim one; it allows one `openTask` per click within a second, and refuses a task the plugin was
  never told about, a done or deleted task, or another task's subagent. After opening, Glade takes keyboard focus
  back from the plugin view — not proven end to end in tests, whose windows are hidden. (#471)
- In the image viewer, only the title moved; Open, Reveal in Finder and Close stay at the top right. When a pager
  button disables while it holds the focus, the focus goes to the viewer itself rather than to the other arrow or
  Close. (#469)
- The switcher's count only counts other workspaces; nothing shows while the sidebar is collapsed, since the
  switcher isn't there. The switcher's accessible name stays "Switch workspace" and the count is given in its
  tooltip. A new colour token, `--color-purple-bg`, backs the pill. (#476)
- A long queued message now wraps to two lines and then ends with an ellipsis; it used to be cut at one line. The
  file chip's icon tile is one step lighter than the chip. (#465)
- Active and Done still show at zero even though Pinned now hides; a folded Pinned section comes back folded once
  something is pinned again. (#458)
- The Linux timing budgets have less margin than the Mac ones, since the runners' processors differ. The release
  workflow still runs the full suite on a macOS runner, timing tests included. (#475)
