Glade 0.8.0 adds a real terminal to the bottom bar, so a shell in your workspace is always a keystroke away.

## What's new

- **The terminal.** The bottom bar holds tabs of real shells (your login shell, zsh by default). Click + or press ⌘T
  for a new tab, which starts in the current workspace's root folder, and the bar shows that folder at its far end.
  Each tab is named after what's running in it, and has a dot while a program runs. The terminal is global: its tabs
  stay put as you move between tasks and workspaces.
- **Shortcuts.** ⌃\` focuses the terminal (opening the bottom bar if it's folded away, and a new tab if there's none),
  ⌘T opens a tab, ⌃⇥ and ⌃⇧⇥ move between tabs, ⌘K clears the tab showing, ⌃C interrupts what runs in it and ⌘W
  (or File › Close) closes it. Like every other shortcut, they're listed in Settings › Keyboard and can be rebound
  there; ⌃C is fixed, since the terminal sends it to the shell.
- **Right-click a tab** for Rename…, Duplicate (a new shell in the same folder, after it), Clear, Kill process and
  Close. A tab also closes itself when its shell exits.
- **Tabs and scrollback persist.** Quit and reopen Glade and your tabs come back, in order and with their names, each
  with its recent output above a line saying it was restored and a new shell below it. Running programs don't survive
  a restart.
- **Run again in terminal.** Right-click a Bash call in the tool log and choose Run again in terminal: its command
  appears at the prompt of the tab showing (or a new tab, if there's none), ready for you to edit or press ↵. It never
  runs by itself.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.8.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.7.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.

Not in this release: the plugin panel beside the terminal (Nekomata in the designs), so the terminal takes the bottom
bar's full width for now.

## Calls made without Jared (please review)

- **Shells.** Tabs run node-pty 1.1.0 (its prebuilt Node-API binary). node-pty 1.1.0 publishes its `spawn-helper`
  without the executable bit, so an install step sets it; the packaged app carries the fixed helper. A tab runs
  `$SHELL` as a login shell, or zsh when `$SHELL` isn't set.
- **No shell until you ask.** The bottom bar starts empty ("No terminal open. Start one with + or ⌘T.") rather than
  opening a shell on launch.
- **Tab names.** A tab is named after its foreground process (the shell's name when it's idle, `sleep`, `npm` and so on
  while a program runs), until you rename it.
- **A shell that exits closes its tab**, rather than leaving a dead tab behind.
- **Scrollback.** Each tab keeps its last 100,000 characters of output across a restart. Processes don't survive a
  restart: the tab comes back with a new shell under a "Restored from the last session" line.
- **No clickable links** in the terminal (xterm.js's web-links add-on is left out).
- **Tested with plain bash.** The tests run `bash --noprofile --norc` with a fixed prompt, so they don't depend on the
  machine's shell setup. Your own shell and its profile have only been tried by hand.

Notable findings from checking the phase:

- **The terminal's tab row has no edge fades.** In a narrow window, the right panel's tab row fades at an edge where
  more tabs scroll past it (0.7.0); the terminal's tab row doesn't yet.
- **Against the design** (`task-workspace`): the tab row, running dots, close buttons, + button, folder and collapse
  button match. The shell's output starts at the top of the screen, where the design draws it sitting at the bottom
  (a real terminal fills from the top), and its lines are slightly further apart than the design's. The prompt's
  colours come from your own shell, not Glade.

## Please check by hand

These need a visible window or your real shell, so the tests can't cover them:

- **Your own shell:** a new tab runs your login shell with your profile (prompt, aliases, PATH), in the workspace's
  root.
- **⌘W with the focus in the terminal** closes the tab, not the window, when pressed on the keyboard (the tests choose
  File › Close instead).
- **⌃C** interrupts a running program, from the keyboard and from Kill process.
