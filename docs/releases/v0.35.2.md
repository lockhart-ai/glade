v0.35.2 fixes GitHub watching: Glade now finds `gh` when it's opened from Finder or the Dock, so notices about linked issues and PRs arrive within a poll instead of up to an hour late.

## What a user notices

- **GitHub notices arrive on time (#718, PR #719).** The watcher reads your token with `gh auth token`, but an app opened from Finder has macOS's bare PATH, without `/opt/homebrew/bin`, so it never found `gh`. It then polled GitHub unauthenticated (60 requests an hour), ran out almost at once and waited out hour-long backoffs. It now runs `gh` with your login shell's environment, as the agents do.

## Under the hood

- The watcher logs to `main.log` under `github`: which way it polls when that changes, a missing `gh` token once, and each backoff with its wait. Never the token (#719).
- CLAUDE.md's code conventions now say a fallback warns in the log, never silently (#720, PR #721).

## Running it

- **Install:** download `Glade-0.35.2-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** no migrations in this release.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
- **Logs:** `~/Library/Logs/glade/main.log`.
