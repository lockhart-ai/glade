Glade 0.20.0 makes "needs you" mean blocked on you or unread, so a reply you've already read stops counting; remembers
each workspace's own right-panel tab; gives the Files tab's Browse tree real file-type and folder icons, indent
guides and sizes; and lets a plugin declare its own settings, so Nekomata can offer a choice of art style from
Settings › Plugins.

## Needs you

- **"Needs you" now means blocked on you: a question, a permission card, an error, or an unread reply.** A reply
  you've already read no longer counts, so a task you've caught up on stops nagging the sidebar, the switcher, the
  menu bar and ⌘⌥↓. A task whose own turn has ended but which still has a subagent, a monitor or a background command
  running now shows as working, not as needing you, until that work finishes or it asks you something. The menu
  bar's label for a waiting reply is now "Unread reply". A new idle state — a slate dot, "Active · idle" — covers a
  task that's caught up with nothing running. (#433)

## Right panel

- **The right panel now remembers its open tab per workspace**, not one tab for the whole app: switching workspaces
  no longer carries over whichever tab you last had open somewhere else. (#436)

## Files tab

- **The Browse tree looks the part now.** Each file gets an icon for its kind (code, prose, stylesheets, config,
  databases, images, lockfiles, Dockerfiles, dotfiles, or a plain file), folders get a closed or open icon, rows get
  indent guides, extensions are dimmed, hover and selection get a visible pill, and each file's size sits in its own
  column at the right. A long name truncates in the middle so its extension stays readable. Browse still only shows
  what's actually on disk — no git status. (#434)

## Plugins

- **A plugin can now declare its own settings.** Its manifest lists a `select` setting — a label, up to 12 options
  and a default — and you set it in Settings › Plugins, beside its capability switches. The page gets the current
  values as `settings` on `snapshot` and a `settings.changed` event whenever they change. Built for Nekomata's art
  style, but general to any plugin. (#437)

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.20.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.19.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- The idle state reuses the done dot's slate colour, labelled "Active · idle"; a brand-new task is idle, not purple.
  Only running work — a running subagent, a running monitor or a running background command — counts as background
  work, not a scheduled wake-up or a cron job. After a relaunch, a task like that is needs-you if its reply is still
  unread, idle if it's been read. An error, a question and a permission card always need you regardless of
  background work. The plugin and control API's `activity` field is unchanged. The README hero and some guide images
  still show the old filter chips and aren't recaptured here (tracked in #427). (#433)
- Each file's size counts in thousands, the way Finder does, not 1024s. Any name starting with a dot gets the
  dotfile icon regardless of its extension. Search results still truncate at the end, not the middle. A file that
  vanishes mid-listing is shown with no size rather than dropped. Five of the kind icons (braces, database, padlock,
  cube and hash) are original outline drawings, since the free icon sets only had them solid or not at all. (#434)
- The right panel's per-workspace tab is stored as one map of workspace id to tab, with the old single global value
  read as the starting point for a workspace that's never chosen one; there's no migration, so nothing moves on
  upgrade. (#436)
- A plugin setting's live changes arrive as a `settings.changed` event, never a reload. A plugin gets up to 8
  settings and each `select` up to 12 options. A saved value that the plugin no longer offers reads as its default
  without rewriting the stored row, so it comes back if the option returns; choosing the default explicitly is still
  stored, so a later change to the plugin's own default doesn't move your choice out from under you. Duplicate
  option values and an empty options list make the manifest invalid, with the reason shown in Settings; a `type`
  this Glade doesn't know is ignored without invalidating it. (#437)

**For Jared to check:** a task with kittens still running that you've already read now shows as working rather than

the Browse tree on a large real workspace, not just the fixtures; and Nekomata's side of plugin settings is a
separate change, in its own repo, not shipped here.
