Glade 0.22.0 is a small release. The workspace switcher's "needs you" count pill now counts every workspace, where
it used to miss tasks in the one you're in; and the image viewer no longer has a moment in which its title could
have been drawn before its image. The release also carries the first parts of the agent sandbox, switched off, and
hardens the git commands Glade itself runs.

- **The workspace switcher's count pill now counts every workspace, the one you're in included.** In 0.21 it left out
  the current workspace, so it could read 2 while the switcher's own dropdown listed three "needs you" rows and the
  menu bar said 3. It now always equals the menu bar's number and the sum of the dropdown's rows. Its tooltip gives
  the total ("2 tasks need you"). Every "needs you" number in Glade is a count of tasks. (#482)
- **The image viewer's title now appears together with its loaded image.** Until now the title was in the page a
  few milliseconds before the image had its size. It was never seen painted out of place, but only timing prevented
  it, and the same moment held a 2-pixel placeholder that is gone too. The test that checks the title's position no
  longer measures before the image has loaded (it had failed once in the merge queue). (#479)

## Under the hood

- **The first parts of the agent sandbox are in, switched off.** The sandboxed agent session (#474) and the store of
  folder and domain grants it reads (#473, a new `sandbox_grants` table, added by a migration when 0.22 first opens
  your data) are in this build. None of it runs: the setting that turns it on (`sandboxEnabled`) is off and has no
  control in Settings yet, so every session starts as it did in 0.21. The permission cards and the Settings page for
  it come in later releases.
- **Glade's own git commands are hardened; this one is on for everyone.** Glade reads repositories for the Changes
  tab and for the Files tab's listing and ignore rules. Those commands now come from a fixed list that only reads,
  ignore every repository setting that names a program to run (hooks, `core.fsmonitor`, editors, credential helpers,
  signature checking, external diff and textconv drivers), and never fetch. What you might notice: in a partial
  clone, a commit whose objects aren't on disk is no longer fetched to be shown; and a commit's diff is git's own,
  never an external diff tool's or a textconv filter's. (#488)
- **The README's and user guide's images were recaptured** from the current app, with a recorded recipe
  (`docs/doc-images.md`) for doing it again. (#481)
- **A failed e2e test now keeps its evidence**: the app's log and the tasks as the main process had them, uploaded
  by CI when a shard fails. (#485)

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.22.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.21.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).
