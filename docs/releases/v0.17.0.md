Glade 0.17.0 marks a paste as its own block for the agent, turns a safety refusal into a quiet notice or a clear
declined card instead of a crash, keeps a subagent off Glade's own tools, and opens images from the Artifacts tab —
and now the Files tab too — in the full-size viewer.

## Pasted text

- **A long paste becomes its own block, not plain text.** Paste more than one line, or about 80 characters, and it's
  marked as its own block: a `[Pasted text · 12 lines]` token, tinted so it stands out from what you typed, sits at
  the point you pasted it, with a matching chip above the field. A shorter paste (a path, a word, a URL) is left as
  plain text, as before. Removing the token or the chip removes the block; typing or editing around it keeps it in
  place.
- **The agent gets it wrapped, so it knows to be wary.** The pasted text reaches the agent inside `<pasted_content>`
  tags at that position in your message, so it can tell your own words from instructions that may be hiding in
  something you pasted.
- **The chat shows one bubble**, your words with each pasted block collapsed to its line count where you dropped it;
  click it to expand the pasted text verbatim in place, scrolling if it's long.

## Safety refusals

- **A refusal answered by a fallback model shows a quiet notice** in the chat — "Answered by claude-sonnet-5: the
  request was declined by a safety check (cyber)" — in place of the refused attempt, whose messages and tool calls
  are gone rather than left duplicated or orphaned; if it switched the whole session, the model picker shows the new
  model.
- **With no fallback, a declined card** takes a crash's place: the error card's own look, the same Retry / Retry
  with another model / Show details, and the task shows under Needs you as "Declined by a safety check," not
  "Stopped on an error."

## Subagents and Glade's own tools

- **A subagent can no longer call `glade` or `glade-control`**, in any permission mode, Allow all included: the
  model gets a tool error telling it to report back instead, and nothing else happens — no question card for a
  refused `ask`, no status, title or objective change, nothing opened in the Files tab or added to Artifacts, and no
  task read, changed or messaged through `glade-control`. A subagent still does its work and reports to the agent
  that started it, same as before.

## Images

- **An image artifact opens in the full-size viewer**, stepping ← → through the task's other image artifacts, with
  its title, Open in Files and Reveal in Finder over it; any other artifact still opens in the Files tab.
- **The Files tab shows an image file as a picture** (PNG, JPEG, GIF, WebP or SVG), fit to the panel and never
  larger than its own size, on a checkerboard behind transparency; click it to open the same viewer, alone.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.17.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.16.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- The paste threshold — more than one line, or about 80 characters — is a guess at where a paste stops feeling like
  something you typed; a shorter one is left as plain text. (#371)
- Blocking `glade-control` for a subagent covers the whole server, its read tools included, not just the ones that
  change something: without that, a subagent would inherit reads (listing, reading and importing tasks) the same
  way the main agent does. (#367)
- A safety refusal's declined card offers no edit-and-retry prefill of the refused message — Glade doesn't have that
  for any error yet — and keeps "The agent stopped" as its heading, same as every other error card, rather than
  wording of its own. (#369)
- A file read from a commit, not the live workspace, still shows the binary notice instead of the picture: only a
  file read from disk now gets the new image rendering. (#373)
- The image cap for a workspace file, in the Files tab and Artifacts, is 8 MB, same as a pasted image; a larger one
  still shows the binary notice, with Open in editor. (#373)
- A missing image artifact stays in the viewer's ← → sequence, shown as a muted placeholder, rather than being
  skipped over. (#373)
