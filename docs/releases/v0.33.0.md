v0.33.0 makes a long task open fast on its latest history, lets an answer to a question card carry images, files and pasted text, shows Stop while a question card waits, and tells the model how Claude Code treats a built-in subagent's worktree and a resumed subagent.

## What a user notices

- **A task opens on its latest history, and older history loads as you scroll up (#637, PR #652).** Switching to a long task used to render every message and tool call before the tab appeared; on a task with about 1,000 messages and 1,500 tool events that was most of the wait. A task now opens on its last 150 messages and tool calls, and scrolling near the top of the chat or the tool log loads the next older page in place, keeping your scroll position. In the #637 measurement on a fast Mac, a switch to such a task took 493 ms with the whole history and about 91 ms with only the tail; on CI's slower runners the new e2e spec measures about 210 ms. What reads the whole history keeps working: the Agents tab loads a subagent's log whole when its tab opens, and revealing a search match or showing a turn from the tool-calls chip loads older pages until it finds what it is after.
- **An answer to a question card can carry images, files and pasted text (#648, PR #651).** While the agent's questions were open, a message with an image, a file or pasted text was refused. A reply typed in the input bar now sends it all: the agent gets each image as an image, pasted text arrives in its place, and each file comes with its path line. What a restarted session is told after it answers late keeps the same attachments.
- **Stop shows while a question card waits (#647, PR #649).** The Stop button shows beside Send and ⌘. stops while a question card waits for an answer; stopping withdraws the questions. Typing a reply still answers them. Permission cards have worked this way since 0.32.0.
- **The model is told how Claude Code treats a built-in subagent's worktree and a resumed subagent (#635, #636, PR #650).** Claude Code removes a built-in `Agent` subagent's worktree when its run changed nothing, and a subagent resumed by message may be shown its siblings' status lines. The delegation append and the dispatch tool now say which kind of child keeps its worktree and what to do for a subagent that plans first.

## Under the hood

- The npm minor and patch group lands 17 updates, among them Electron 44.4.5 to 44.7.0 and Playwright 1.63.0 to 1.64.0 (PR #638).
- Design screen 3 (a rich question) now shows the Stop button beside Send, with its PNG re-rendered (#649).
- A new e2e spec, `history-tail`, holds a switch to an unvisited long task under a 450 ms median and checks the scroll position is kept; `typing-latency` counts the tail a task now shows (#652).
- The `history-tail` spec seeds only the tasks it measures, so it launches quickly on CI, and times a switch by the new task's own rows (#654, PR #655).
- `docs/sdk-notes.md` §19 records both subagent behaviours as read in the bundled Claude Code 2.1.283, marked "read in the bundle, not probed live" (#650).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.33.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.32.0 carry over.
- **Database:** no migrations in this release; your database opens as it is.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- The image viewer's list of a chat's pasted images covers only the messages loaded so far; older ones join the list as you scroll up (#652).
- A reply's tool-calls chip counts its turn's calls among the loaded log, so for the one turn straddling the tail's edge it can read short until that page loads (#652).
- An image dropped or attached as a file reaches the agent as its path only, not as an image; only images sent as images become image blocks (#651).
- A very small image can fail: the 8 by 8 probe image was rejected as unprocessable by the API, and real pasted screenshots are far larger (#651).
- The new e2e spec's switch budget is a 450 ms median: about twice what CI's runners measure, well under the whole-history switch (#652, #654).
- The worktree distinction lives in the delegation append, which only OpenRouter-connected sessions get, not as a new line in the main system prompt; a main-prompt line would need an `INSTRUCTION_UPDATES` entry for resumed sessions (#650).
