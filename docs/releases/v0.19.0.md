Glade 0.19.0 lets you attach any file by dragging it in or pasting it from Finder, adds a Browse tab to explore the
whole workspace, turns PRs, issues and tickets into artifacts you can click back to, lets a plugin opt in to the
Mac's CPU, GPU and Docker load, makes every question on a question card optional with room for a note of your own,
puts every agent reply on the purple card and drops the sidebar's filter chips, shows a Log in button when your
Claude Code login expires, and fixes a Subagents tab that lagged behind a woken subagent, a terminal that could sit
below the fold, laggy typing in a long task, a wrong context-window reading, and a chat input that didn't always
take focus.

## Attaching files

- **Attach any file by dragging it onto the input bar, or pasting it copied in Finder (⌘V).** Glade copies it into
  the workspace (`.glade/attachments/<task>/`) and tells the agent its name, size and path as a line at the end of
  your message — never its contents — so a CSV or a PDF reaches it without you pasting it in by hand. An attached
  PNG, JPEG, GIF or WebP also goes to the agent as an image. A chip in the input bar, the chat and a queued message
  shows each attached file; click it to open it or reveal it in Finder, ✕ to remove it before sending. A folder, or a
  file over 200 MB, is refused with a toast. (#405)

## Files tab

- **A new Browse tab lists the whole workspace, not just the files the agent has opened.** A lazy tree, folders
  first, hides `.git`, `.glade` and whatever git ignores; a search across the whole workspace finds a file by name
  or path from anywhere, best matches first. Arrow keys navigate it, a blue dot marks a file the agent has changed,
  and each task's open folders are kept across a relaunch. (#408)

## Artifacts

- **Artifacts can now be links, not just files.** `add_artifact` takes a URL as well as a path; Glade recognises a
  GitHub PR or issue, a Jira ticket or any other page and shows it with its own icon (`#412 · acme/api`, `API-123`,
  or its domain). A new All · Files · Links filter appears once a task has both kinds, and every link in the chat
  gets Add to artifacts on its menu. The agent is asked, in its system prompt, to add the PRs it opens and the
  tickets a task is about. (#425)
- **The Artifacts tab opens the group with the newest artifacts to begin with, not just Today or Yesterday.** A task
  whose newest artifacts are from last week no longer looks empty until you open a group by hand; a group you've
  folded or opened yourself still wins over the default. (#406)
- **A stale history load can no longer undo an artifact's removal.** Removing an artifact while an older load of the
  task's history was still in flight could bring it back once that load answered; artifacts are now versioned, so a
  load that started before a change never overwrites one that landed after it. (#400)
- **Pressing ← or → the instant the image viewer opens no longer gets lost.** It now takes the focus synchronously,
  from the close button's own mount, instead of waiting a frame for the viewer's portal to settle. (#401)

## Plugins

- **A plugin can ask to see the Mac's CPU, GPU and Docker load.** It's opt-in per plugin, off until you switch it on
  in Settings › Plugins ("Can see your Mac's CPU, GPU and Docker load"); turned on, Glade samples it every couple of
  seconds while the plugin is on, showing and ready, and sends it readings shaped for a dashboard like Nekomata's.
  (#414)

## Questions

- **Every question on a question card is now optional, and every card ends with an "Anything else?" box.** Send
  answers to any subset of the questions, or none, and add a note of your own; Send is always available (it reads
  Skip while nothing is answered or typed), and a skipped question shows as "Skipped" on the answered card. (#404)

## Chat and sidebar

- **Every agent reply sits on the purple card**, not just the latest one: a newer message no longer turns the one
  before it grey. Only what the agent said right before asking a question with no preamble keeps the neutral card.
  (#419)
- **The sidebar's All · Needs you · Unread filter chips are gone.** The Pinned, Active and Done sections, plus the
  rows' own dots, the header's state dot and the menu bar, already say what needs you or is unread; ⌘⌥↓ (next task
  that needs you) and ⌘⇧U (mark as unread) still work. (#419)

## Signing in

- **A logged-out task shows a Log in button, not a generic API error.** Glade now tells a lost Claude Code login
  apart from other failures and offers Log in (which opens the browser to sign back in, through the bundled Claude
  Code binary), Retry, Retry all and Show details; Settings › General offers the same Log in while you're signed
  out. A task retried after signing back in starts over with the new login. (#423)

## Fixes

- **A subagent woken by `SendMessage` after it had finished, failed or was interrupted by a relaunch now shows as
  running again**, in the Subagents tab, the task list's count and the plugin feed, instead of staying stuck on its
  old state while it actually ran. (#402)
- **A relaunched terminal's prompt no longer sits below the bottom of its card** until you reopen the tab: Glade now
  waits for its font to load before sizing a terminal, and refits it whenever its own measurements change. (#417)
- **Typing in a task with a long history no longer lags behind a busy turn.** Each chat and tool-log row, and each
  subagent row, now renders only when its own data changes, and the chat, tool log and Subagents panels no longer lay
  their contents out twice; the median time from keystroke to paint in a 500-message task fell from 1087 ms to 6 ms.
  (#422)
- **The context meter no longer shows the wrong window, or a raw model id like `opus[1m]`, for a 1M-token session.**
  Glade now matches the window the SDK actually reports to the task's model, remembers it, and shows the next window
  up whenever more has been used than the guessed one holds. (#424)
- **The chat input now gets focus whenever you switch tasks or start a new one** — clicking a row, the keyboard, a
  notification, the menu bar popover, search, a workspace switch, a relaunch or a closing dialog all land you in the
  input now, not just the routes that already worked. (#426)

## Under the hood

- Moved `static` (typecheck, lint, format, build) and `unit` (`npm test`) to Linux runners, since GitHub queues
  macOS runners far behind Linux ones; `check-design` and the three `e2e` shards stay on macOS, where pixel
  comparisons and the real app's behaviour need it. (#420)

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.19.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.18.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- The reply right before a question with no preamble still keeps the neutral card; every other agent reply is purple
  now. An old stored sidebar filter (All, Needs you or Unread) is left in the database but ignored, not migrated to
  anything: every task shows regardless of what used to be saved. The chips are gone from the app and the design
  screens, but other screenshots across the README and the user guide still show them; a follow-up issue (#427)
  tracks re-capturing those. (#419)
- The image viewer still returns focus to its own row when it was opened from the Artifacts or Files tab; opened
  from a chat image, closing it focuses the chat input, like every other route now does. (#426)
- Glade only lists the 1M context variants the SDK itself reports, rather than inventing one for a model that
  doesn't have it; when more has actually been used than the guessed window holds, it shows the next window up
  instead of the one it guessed; and the window it lands on is remembered per model, not just per task. (#424)
- A link artifact refuses a URL that isn't http or https, carries credentials, or runs past 2048 characters. An
  artifact can't change kind: a file takes a new path and a link takes a new URL, and turning one into the other
  means removing it and adding the other. A session started before this release is told about link artifacts once,
  on its next message, as a line appended to the agent's instruction updates. The control API's artifact output now
  carries a `kind` field. Add to artifacts on a link's menu adds it straight away, with no title prompt. (#425)
- A Log in button shows in Settings › General only while you're signed out or a task is logged out; there's no Log
  out button yet. A task's Claude Code process restarts with the new login on retry only if it has no background
  work running — one with background work waits instead. (#423)
- A file over 200 MB is refused with a toast — a guess at a sensible ceiling, not a number any doc sets. A symlink
  dropped or pasted is copied as its target, not kept as a link, and a name that collides gets a `(2)` suffix rather
  than overwriting. The attachments folder is kept out of git through the repository's own `.git/info/exclude`,
  never a committed `.gitignore`, so a workspace's own checked-in ignore file is left alone. A done task keeps its
  attached files; only deleting the task deletes its folder. (#405)
- Machine sampling runs only while a plugin with the capability on is on, showing and ready, about every 2 seconds —
  a cadence chosen to be cheap, not specified anywhere. `docker stats` runs with a timeout and never starts Docker
  itself, so a plugin can't make Docker start running just by asking for its load. This reverses P12's decision that
  a plugin gets nothing about the machine (`docs/decisions.md`); the capability stays opt-in per plugin, off by
  default, to keep that true unless you turn it on. (#414)
- A text question's own `optional` flag is still accepted from the agent but ignored now that every question is
  optional. Sending with nothing answered or typed shows as Skip, and the answered card reads a lone "· skipped"
  rather than listing every question as skipped one by one. (#404)
- Outside a git repository, Browse hides only `.git` and `.glade` — there's no ignore file to defer to, so nothing
  else is hidden. A symlink shows only when it leads back inside the workspace root, and search never follows one
  into a symlinked folder. Search stops at 200 matches with an "N more…" count rather than listing everything; ⌘F
  only reaches Browse's own search while the Files tab has focus and Browse is showing, leaving the code editor's
  own ⌘F alone. (#408)
- The macOS-only machine-sampler integration test (gated since #414, real `ps`/`ioreg`/`docker` calls) now runs as
  its own step in the `check-design` job, since `unit` moved to Linux and would otherwise lose that coverage. (#420)
