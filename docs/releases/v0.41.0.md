v0.41.0 tells agents on OpenRouter what the key has spent today, instead of its all-time total.

## What a user notices

- **Agents see today's OpenRouter spend (#774, PR #775).** The usage line at the end of each prompt, and the note when spend crosses another step, used to give the key's all-time total as just "OpenRouter spend", so agents took a large running total for their own cost. They now say "OpenRouter spend today (UTC) $2.14" and "OpenRouter spend today (UTC) is now $10.02", matching the meter's Today row. The steps start over each UTC day.

## Under the hood

- When today's spend is lower than the last figure a task was told (the UTC day has turned, or, just after updating, the last note named the all-time total), the baseline resets quietly, so no false note goes out (#775).

## Running it

- **Install:** download `Glade-0.41.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** no migrations in this release.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
