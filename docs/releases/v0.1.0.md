Glade 0.1.0 is the first release: the core loop. Run a Claude agent as a task in one workspace, from the first message
to done.

## What it does

- **Workspaces.** On first launch, pick a folder. It becomes your workspace and reopens on every launch. If the folder
  has no `CLAUDE.md`, Glade writes a starter one.
- **Tasks.** ⌘N or + starts a task. Your first message starts an agent session in the workspace folder. The agent names
  the task, sets its objective and keeps its status current in the header and sidebar.
- **Chat and tool log.** The chat shows your messages and the agent's final reply for each turn. Every tool call and
  working note goes to the tool log, split by turn.
- **Control.** Pick the model and effort per task, watch the context meter, and stop the agent with ⌘. or the Stop
  button.
- **Done and reopen.** Mark a task done (⌘⇧D), and Undo if you didn't mean to. Send a done task a message to reopen it
  in the same session.
- **Crash-safe.** Everything lives in a local SQLite database. Force-quit mid-turn, relaunch, and the task carries on.

See it in action: [recordings of each workflow](https://github.com/lockhart-ai/glade/issues/15#issuecomment-5808972031).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.1.0-arm64.dmg` below, open it and drag Glade to Applications.
- **Unsigned build:** Glade isn't signed or notarized yet, so macOS blocks the first launch. Right-click Glade and choose
  Open (on newer macOS, try to open it once, then click Open Anyway in System Settings → Privacy & Security). If macOS
  says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and open it again.

Not in this release: parallel tasks, the message queue, and the terminal and plugin panels. Those come in later phases.
