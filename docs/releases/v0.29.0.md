0.29.0 makes todos survive a session restart so an agent can still reach and close them, adds token totals and context figures to the Agents tab, and fixes a terminal prompt that typed old answers into a new shell.

## What a user notices

- **Todos survive a session restart (#593; PRs #594, #598, #605).** A task now keeps one todo list across session restarts, so its agent can still reach and update its todos afterwards. Todos left behind from before this (the agent can no longer reach them) are shown in their own Stranded group on the Todos tab, after the live todos and before "Not under a todo", with a dashed ring; they are left out of the tab's heading, bar and badge. The agent is told which of its todos are stranded and has a new `close_todo` tool to close one once anything filed under it has been moved to a current todo (#598).
- **Terminal: no junk text at the prompt after a restart (#603, PR #604).** A restored tab's old output is replayed without the terminal's answers to old queries being typed into the new shell.
- **Agents tab: token totals and context size.** A dispatched child's token totals show on its line (#591); a native subagent's context size shows on its line (#595).
- **A task's agent can message a dispatched child while it runs (#597).**
- **Settings › Models: bad entries skip, rows stay visible (#600).** A bad entry in the model catalog no longer fails the refresh, and the Selected rows stay visible.

## Under the hood

- `docs/conventions.md` (#602): one form for naming tasks, issues, branches, commits, PRs, todos and artifacts; the project `CLAUDE.md` loads it.
- Migrations 0070 (agent call token totals), 0071 (agent call context tokens) and 0072 (retired todos). Migrations only go forward: a database opened by 0.29 can't be opened by 0.28.
- The capture seed can now seed stranded todos (#605).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.29.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.28.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).
