Glade 0.15.0 moves the traffic lights into the sidebar, puts a usage meter where the usage banner used to be, gives
every workspace its own terminal, and makes every link in the app clickable.

## The chat

- **Click a pasted image to see it full size.** Chat and queue thumbnails are buttons now, with a pointer and a focus
  ring; a click, ↵ or Space opens an image viewer sized to fit the window (never larger than the image itself), with
  a pager for several images that wraps round at the ends. Esc, a backdrop click or × closes it.
- **Links are clickable everywhere.** Markdown links and plain-text URLs in replies, questions, tool output, todos,
  watcher lines and queued messages now open in your browser (`mailto:` links in your mail app) on click, with their
  own Open link and Copy link menu.

## The sidebar and menu bar

- **The traffic lights sit in a strip at the top of the sidebar.** The empty title-bar row (#195) is gone; the
  sidebar and task cards now start at the window's edge, and the workspace switcher's hover and open box line up
  with the card around it.
- **A usage meter replaces the usage banner.** A small ring at the foot of the sidebar always shows the limit
  closest to running out and when it resets, reading straight from the SDK's usage call; open it for a popover with
  every limit, your plan, and when it last updated.
- **The menu bar icon no longer pulses.** It's the plain template glyph with the Needs you count beside it; the
  popover is unchanged.

## Tasks

- **Stop is an icon-only button**, the same size as Send and lined up with it. It keeps its accessible name and
  shows its shortcut in its tooltip.
- **Todos put what's still to do first.** The Todos tab now orders active items, then what's not started, then
  what's completed (most recently finished first), so finished work no longer pushes what's left further down.

## The terminal

- **Each workspace has its own terminal tabs**, not one shared set. Closing a workspace keeps its shells running in
  the background so their output is there when you switch back; removing a workspace ends them.

## The agent and the SDK

- **The Claude Agent SDK is bumped to 0.3.283**, bundling Claude Code 2.1.283. Nothing Glade relies on changed shape.

## Under the hood

- **Dependabot now runs weekly**, grouping the SDK and its platform packages into one pinned bump and everything
  else by minor/patch, with majors opened one PR at a time. Four majors are held back deliberately for now:
  `@types/node` (must track Electron's bundled Node), `typescript`, `eslint` and `vite` (each blocked on a
  dependency that doesn't support the new major yet).
- `diff` moved to 9.0.0 and `jsdom` to 30.1.1, both routine dependency bumps with no code changes needed.
- Three flaky tests were fixed: the Claude Code import timing budget (it now compares against a reference timed on
  the same machine, rather than a fixed CPU budget), a watchers spec that could catch a scheduled job's due time
  crossing "now" mid-check, and a notifications spec where a scripted reply could arrive before the window told
  main it had switched tasks.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.15.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.14.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- The traffic lights sit at `{ x: 16, y: 16 }`, centring AppKit's 14px circles in the 28px strip; checked against
  AppKit's own drawing of the buttons in the running app. While the app-wide banner shows, it appears below the
  strip and the sidebar and task cards fold their own strips away, since the window has already grown to make room.
  (#325)
- The usage meter is hidden for an API-key or cloud-provider account, since the SDK's usage call doesn't apply to
  them. It shows the limit closest to running out (session, this week, a model's week, or extra usage), turning
  purple from 70% used. (#332)
- Links aren't rendered inside buttons, and a link Glade refuses to open (anything but `http:`, `https:` or
  `mailto:`) still shows as plain text rather than disappearing. (#350)
- The image viewer's pager wraps round: stepping past the last image goes to the first, and back past the first
  goes to the last. (#326)
- A window with no workspace open keeps its own terminal tabs, separate from any workspace's. (#348)
