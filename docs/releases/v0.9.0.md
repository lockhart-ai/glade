Glade 0.9.0 is the first dogfooding release: fixes and polish from running Glade on itself, a real log, and a Done
list that stays fast however long it gets.

## Fixed

- **Agents have your shell's tools.** Opened from Finder or the Dock, agent sessions used to get macOS's bare PATH, so
  Homebrew, nvm, pnpm and `~/.local/bin` tools were missing. Glade now reads your login shell's environment at startup
  (and carries on without it if your profile is slow or broken).
- **Turns the agent starts itself are kept.** When a background command or subagent finishes, or a timer fires, the
  agent works on its own. That turn used to vanish; now it's shown and saved like any other, with unread and a
  notification.
- **Background subagents show their real state.** A subagent started in the background stays Running in the
  Subagents tab until it really finishes, and the parent task goes back to waiting on you, so you can keep talking to
  it meanwhile.
- **Subagents' tool calls live under the subagent.** The Tool calls tab shows only the task's own calls; each
  subagent's calls are under its entry in the Subagents tab.
- **The Todos tab fills with a real model.** Claude Code leaves its todo tools off for SDK sessions on newer models;
  Glade now turns them on.
- **Resize handles don't skip steps** when you hold an arrow key, and the chat stays pinned to the bottom when the
  window shrinks.

## New

- **Paste text and images** into the input bar. Images (PNG, JPEG, GIF, WebP, up to 3.75 MB each) show as thumbnails
  you can remove, go to the agent with your message, and stay in the chat after a relaunch.
- **The agent can schedule its own follow-ups.** It can watch a command (`Monitor`), check back later
  (`ScheduleWakeup`), schedule a job (`CronCreate`), or run a command or subagent in the background, end its turn,
  and pick up again by itself. Each wake is a turn in the chat.
- **A calmer, tighter window.** Spacing comes in and everything lines up on shared edges; the window controls have
  their own title bar row; the task header is one compact line above the objective and status; the task list and the
  bottom bar resize like the side panel does; and panels, sections, toasts, menus and the question card animate
  (not if you've turned on Reduce motion).
- **The Done list stays fast** at thousands of tasks: it loads a page at a time and draws only the rows in view. It
  looks and works as before, and now scrolls to the selected task.
- **Logs.** Glade writes a structured log of what it does (app start, sessions, turns, tool calls, errors) to
  `~/Library/Logs/Glade/main.log`. Secrets are redacted and message text is cut short. See `docs/logs.md`.

The groundwork for per-call permission review is in this build too, but there's no way to turn it on yet; that
comes in 0.11.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.9.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.8.1 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/Glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- A self-started turn on a done task doesn't reopen it; it stays done while the turn runs and the reply is saved. (#162)
- A self-started turn clears an error or pause like any new turn, so the paused turn's automatic retry is dropped. (#162)
- If you send a message just as the SDK wakes itself, the self-started reply can land in your message's turn; your answer then gets its own turn. Nothing is lost. (#162)
- A self-started turn runs on the session's current model and effort. (#162)
- Glade always turns on Claude Code's todo tools (CLAUDE_CODE_ENABLE_TODO_TOOLS=1), even if your shell turns them off, because the Todos tab depends on them. (#167)
- Added `npm run render-design`: there was no tool to re-render the design screens. (#170)
- Only the app shell and the right panel's tabs were tightened; dialogs and menus (Settings, context menus, keymap) keep their spacing. The shared Input is now 32px everywhere, including Settings and the question card. (#170)
- Chat messages now run to the column's edges, level with the header card and input bar (they were 20px in). (#170)
- Pasted images are stored in SQLite as BLOBs (a new `images` table), tied to their message or queued message. (#169)
- Only PNG, JPEG, GIF and WebP are accepted, at up to 3.75 MB each (the API's 5 MB after base64). There's no limit on how many. (#169)
- A paste that carries any text is treated as text only and attaches nothing. (#169)
- Images can't go with a reply to an open `ask` question, which is text only; the bar says why and keeps them. (#169)
- Queued messages show small thumbnails. There's no click-to-enlarge for images in the chat. (#169)
- The task list now scrolls to the selected task when it's off screen, in every section. Nothing did this before. (#67)
- The Done section loads 100 tasks at a time, and its scrollbar grows as pages load. (#67)
- The first Done page loads even while the section is collapsed, so opening it is instant. (#67)
- Logging uses electron-log: JSON lines in ~/Library/Logs/Glade/main.log, rotating at 5 MB and keeping 5 old files. Debug level is always on; there's no setting yet. (#176)
- Message text and tool input/output appear only on debug lines (excerpts of up to 500 chars). Terminal input/output and IPC payloads are never logged. (#176)
- The task title token went from 26px to 20px, which also shrinks the loading and error screen. The activity pill can truncate, capped at 40% of the line, so a long title still shows at small sizes. (#172)
- The title bar row is 32px, with the traffic lights at (12, 8). "Show task list" stays where it was and just relies on the row for clearance; it didn't move into the title bar. (#171)
- In full screen the row keeps the same height. This wasn't tested, to avoid opening windows. (#171)
- The sidebar resizes between 240 and 520px. The bottom bar's minimum is 120px, and the task card always keeps at least 460px of height; the old 30vh cap on the bottom bar is gone. There's no double-click reset, because the right panel doesn't have one either. (#173)
- A subagent you stop shows as "Failed", with "You stopped the subagent." (#165)
- Background Bash commands aren't tracked beyond their launch (out of scope). (#165)
- The Tool calls count now counts only the parent's own calls. In the Subagents tab, each call's result shows through its dot, with its output a click away, as in design 11. (#166)
- Motion is CSS only: 200ms ease-out for panels, sections, toasts and the question card; 120ms for menus and popovers. Reduce motion drops every duration to 0ms. (#174)
- The message queue doesn't animate. Menus fade in but close instantly. The question card rises in only when it was asked in the last 2s. Nothing already on screen animates in when a view opens. (#174)
- e2e runs with reduced motion by default; only the animation specs turn motion on. (#174)
- Every follow-up tool (Monitor, ScheduleWakeup, CronCreate, background Bash and subagents) already works in SDK sessions, so Glade turns nothing on. Stop ends only the turn a follow-up woke; it doesn't cancel pending wakeups, cron jobs or watches. (#168)

## Open questions

- **Follow-ups you can't see (#168).** A pending wakeup, cron job or watch shows nowhere in the task, and the only way
  to cancel one is to ask the agent. Should it show, e.g. on the status line?
- **Follow-ups on a done task (#168).** Marking a task done doesn't cancel its jobs, so a later wake runs a turn in the
  done task (it stays done, with unread and a notification). Should Mark done cancel them, or the wake reopen it?
- **Follow-ups across a relaunch (#168).** Glade only resumes sessions that were mid-turn, so an idle task's cron jobs
  don't fire until you next message it, and `ScheduleWakeup`s are lost. Should Glade resume sessions with pending
  jobs at launch?
- **Background subagents (#165).** The parent that stayed "working" in your dogfooding session was waiting on a
  foreground subagent, which genuinely holds the turn. Should Glade nudge the model towards background subagents?
- **A link from the tool log to the subagent (#166).** A subagent's `Agent` row is a plain row. Want it to jump to the
  Subagents tab?
- **Retry after a self-started turn fails (#162)** resends your last message, as retry always has. Right?

## Please check by hand

- **Opened from Finder or the Dock,** an agent's `which node` (or `brew`, `gh`) finds your tools.
- **Paste** a screenshot into the input bar and send it; the agent sees it.
- **Ask the agent** to keep a todo list (the Todos tab fills), to start a background subagent (the parent stays free
  while it runs), and to check back in a minute (`ScheduleWakeup` wakes it by itself).
- **The window:** traffic lights in their own row, dragging the row moves the window, double-clicking it zooms;
  resizing the task list and bottom bar; animations, and none with Reduce motion on.
- **The log** at `~/Library/Logs/Glade/main.log` follows a task from your message to its reply.
