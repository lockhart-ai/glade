v0.38.0 lets a GitHub notice reach an agent that's waiting on your ask card, and takes a batch of patch-level dependency updates.

## What a user notices

- **GitHub notices get through while an ask card is up (#759, PR #760).** An agent waiting on your answers used to sit on a GitHub notice until you answered. Now the notice ends that wait: the agent is told you haven't answered yet, the card stays open, and it shouldn't ask again; the notice then starts its next turn. Your answer, whenever you give it, reaches the agent as a message.

## Under the hood

- Patch-level updates: React and React DOM 19.3.1, Electron 44.7.2, Vitest 5.0.4, zod 4.6.7, Playwright 1.64.1, TanStack Virtual 3.14.19, jsdom 30.1.3, typescript-eslint 8.71.2 (PR #706).
- A message queued while a card is open, but with nothing waiting on it any more (after a relaunch, or a GitHub notice), is delivered at once instead of waiting for the answer (#760).

## Running it

- **Install:** download `Glade-0.38.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** no migrations in this release.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
