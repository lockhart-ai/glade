v0.37.0 tells a task's agent where its notes live, keeps the task list's place when Done opens, and lines the Agents tab's watcher count up with its label.

## What a user notices

- **A task's agent knows its notes folder (#751, PR #754).** A task with an external id (set with the control API's `update_task`, usually the folder its notes live in) has it named in its session's system prompt. A session that's resumed, or already running when the id is set or changes, is told once in a short note ahead of its next message; a relaunch neither loses nor repeats it.
- **Opening Done keeps your place in the task list (#753, PR #757).** The list no longer jumps to the top, and a selected done task isn't scrolled to again each time Done reopens.
- **The Agents tab's watcher count lines up (#752, PR #755).** The eye and its count sit on the same line as "Agents" and its count.

## Under the hood

- A capture or e2e seed naming a retired panel tab id now fails with an error naming it, and the three fixtures that did are fixed (#744, PR #756).

## Running it

- **Install:** download `Glade-0.37.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** one migration, forward only: 0084 records which external id each session was told.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
