Glade 0.16.0 turns the Files tab into an editor, adds click-to-copy for code everywhere Glade shows it, and moves the
traffic lights into the task header while the sidebar's collapsed — plus the animation fix that regression needed.

## The Files tab

- **Edit a file, not just view it.** Any workspace file that isn't from a commit, binary, or too large to show whole
  now opens for editing with CodeMirror 6, styled only from Glade's tokens so at rest it's indistinguishable from the
  read-only viewer: same size, line numbers and colour, the viewer's own Shiki syntax highlighting kept live as you
  type. ⌘S saves through the same workspace-scoped path reading already used; ⌘F opens Glade's own find bar, and Tab
  indents.
- **A dot marks unsaved edits** where the tab's × sits. Closing the tab, switching task or workspace, closing the
  window or quitting all ask Save / Discard / Cancel first.
- **The agent's own edits still show up.** With no unsaved edits of your own, a change from the agent reloads
  quietly, keeping your scroll position; with unsaved edits, a bar under the tabs says the file changed on disk and
  offers Reload or Keep mine.
- **The header holds up in a narrow panel:** it drops how the file was last touched, then shrinks Open in editor to
  its icon, before anything gets cut off.

## The chat

- **Click code to copy it.** A code span (`like this`) clicks, or Enter, to copy its exact text, with a small
  Copied shown beside it for about a second; a drag selection is left as ordinary text. Fenced code blocks, and a
  permission card's command or change block, get their own copy icon in the corner, shown on hover or focus.

## The sidebar

- **The traffic lights move into the task header's first row** while the sidebar's collapsed, left of Show task
  list, the state dot and the title, following up on 0.15's feedback (#325). The strip above the task card is gone;
  the header rises to the window's own outer inset in its place.
- **The sidebar and right panel slide smoothly again.** 0.15.0's traffic-lights strip dragged the window on every
  frame of a slide, stalling it to about 1 fps; the strip (and the title row shown with no task open) now drags the
  window only while nothing beside it is sliding.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.16.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.15.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- Unsaved edits in the Files tab live in the window, not SQLite: the file on disk is the file, so nothing halfway
  edited persists across a crash or restart. (#353)
- The unsaved dot replaces the tab's × rather than sitting beside it, so the tab doesn't grow or shift when it
  appears. (#353)
- The icon-only Open in editor, once the panel narrows past 560px, keeps its outline rather than turning into a bare
  icon with no border. (#353)
- User messages' own code isn't click-to-copy: they render as plain linked text, not Markdown, so there's no code
  span to click in the first place. (#359)
- The "Copied" tag sits beside an inline code span, where the block's copy button shows it above itself instead.
  (#359)
- The collapsed lights sit at `{ x: 34, y: 34 }`, the room AppKit's own cluster measures at that size. (#361)
