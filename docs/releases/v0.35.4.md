v0.35.4 keeps a linked issue's or PR's state current after its todo is done, so a closed issue or merged PR no longer shows as Open in the Todos tab.

## What a user notices

- **Linked issues and PRs stop showing a stale "Open" (#738, PR #739).** Glade used to stop checking a link the moment its todo was marked done, often while the issue was still open, so the row kept saying Open after GitHub closed it. It now keeps checking every linked PR until it merges or closes and every linked issue until it closes, whatever its todo says. A change on a done todo's link updates the row but doesn't wake the task. Links already stuck at Open correct themselves on the first poll after you update.

## Under the hood

- The log notes when a done todo's link changes state (`github` scope), never a poll that found it unchanged.

## Running it

- **Install:** download `Glade-0.35.4-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** no migrations in this release.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
