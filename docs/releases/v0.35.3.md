v0.35.3 fixes what tripped up 0.35.2: a todo link no longer shifts the whole window up, GitHub notices no longer show in the queue box, older tasks learn they can set a todo waiting, and a collapsed todo's summary line is evenly spaced.

## What a user notices

- **A todo link scrolls only the todo list (#734, PR #735).** In 0.35.1 and 0.35.2 a todo link could push the whole window up under the traffic lights; only the list moves now. If your window is still shifted, quitting and reopening Glade puts it right.
- **GitHub notices stay out of the queue box (#733, PR #736).** A notice waiting for the agent's turn to end is still delivered, but the queue box above the input bar no longer lists or counts it.
- **Older tasks set a todo waiting (#725, PR #726).** The todo tools line now says `update_todo` takes status "waiting" even where a task's tool list doesn't show it; every task is sent the new wording once.
- **A collapsed todo's summary line is evenly spaced (#723, PR #724; #727, PR #729).** One gap between every count and GitHub entry, including between a link's number and its state, and no separator dots.
- **A merge right after linking is no longer missed (#728, PR #730).** A link's first check reports a merge or close GitHub dates after the link was added to the task; older changes stay silent, as before.

## Under the hood

- The usage-line test no longer fails within a session of midnight UTC (#731, PR #732).

## Running it

- **Install:** download `Glade-0.35.3-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** no migrations in this release.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
- **Logs:** `~/Library/Logs/glade/main.log`.
