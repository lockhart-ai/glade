0.30.0 moves todos from Claude Code's list into Glade's own database, adds a task's note to every todo, and puts the tasks that need you at the top of the workspace switcher.

## What a user notices

- **Todos live in Glade's own database (#609; PRs #613, #618, #619).** v0.29 kept a task's todos in Claude Code's own list on disk, which a task that had ever switched to an OpenRouter model lost on every restart, so its todos showed as "Stranded" (#607, #608). Now Glade keeps every task's todos in its own database and gives the agent its own todo tools (create_todo, update_todo, list_todos); Claude Code's built-in todo tools are switched off. A task's todos survive restarts, model switches and relaunches; nothing is stranded any more, so the Stranded group and close_todo are gone. Every task's existing todos are carried over with their numbers, text, state and finish times, and a number is never given out twice.
- **A todo's note shows in any state (#618).** The one line under a todo's title now shows for a not-started todo too, not only one in progress, and a note given when a todo is completed is kept.
- **Workspace switcher: jump straight to a task that needs you (#610, PR #616).** Under each workspace, the tasks that need you are listed one per line (dot, title, time), newest first, at most four then "+N more"; clicking one switches workspace and opens that task.

## Under the hood

- Migrations 0073 (Glade's todo tables), 0074 (carries every task's todos over) and 0075 (drops the old retired-todos table). Migrations only go forward: a database opened by 0.30 can't be opened by 0.29.
- The shared Claude Code list folders from 0.29 (sdk-task-lists) are no longer read; they are left on disk.
- A sandbox end-to-end test that still drove the old built-in todo tool was moved to Glade's own (#618).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.30.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.29.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).
