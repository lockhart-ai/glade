Glade 0.5.0 fills in the right panel: beside the tool log, each task now shows the files it touched, its checklist,
its deliverables and its subagents.

## What's new

- **Five tabs, counted.** Tool calls, Files, Todos, Artifacts and Subagents, each with a count when there's something
  to count. ⌘⌥1–5 picks one, dragging the panel's edge resizes it (kept across launches), and ⌘⌥B or the collapse
  button hides it; the task header offers it back.
- **Files.** A list of the files the task changed and read opens each one in a tab, in a read-only viewer with line
  numbers and syntax colours. A blue dot marks a file the agent changed. Markdown files have a Preview. Open in editor
  opens the file where you edit code, and ⌘W, with the focus in the panel, closes the file showing. The agent can open
  a file there for you, at a line, with its new `show_file` tool, even if the panel is collapsed.
- **Todos.** The agent's own checklist, as it keeps it: done, in progress and to do, with "3 of 7 done" and a progress
  bar, and the tally in the tab. It's worked out from the tool log, so it's still there after a restart.
- **Artifacts.** The agent names its deliverables with the new `add_artifact` tool, and each shows as a card with its
  type, length and age, and Open, Copy and Reveal in folder. They stay after the task is done. A file that's since
  gone shows as missing.
- **Subagents.** A tally and a row per subagent, running ones first: its status, its latest call or what it last
  said, how long it's run and how many tool calls it's made. Click one to open its log inline.

Also in this release: the task header stays compact in a narrow window, with the chat still visible and scrollable
above the input bar; and a few task actions from P6 landed early: F2 renames the selected task inline in the task
list, ⌘⇧P pins or unpins it, and deleting a task asks for confirmation first (the Delete task… command itself comes
with the task context menu in a later release).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.5.0-arm64.dmg` below, open it and drag Glade to Applications. Your tasks from 0.4.0
  carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.

Not in this release: the terminal and plugin panels, search, context menus and Settings. Those come in later phases.

## Calls made without Jared (please review)

- **Tested with a scripted agent only.** Every tab has been exercised against Glade's scripted fake agent in the tests,
  not a real model.
- **Please check ⌘W by hand.** In the Files panel, ⌘W closes the file showing only while the focus is in the panel.
  The e2e spec covers that, but it can't see the app menu, so check in the real app that it doesn't also close the
  window.
- **The right panel's selected tab is app-wide,** not per task. Collapsed means hidden, with a Show side panel button
  in the task header; there's no design for a rail. Its width runs from 320px to as wide as leaves the chat 380px.
- **Files:** the Files count is the number of open file tabs. The list comes from finished tool calls, subagents'
  included. `show_file` opens the panel only when you're viewing that task. Files over 512 KB or 5,000 lines aren't
  shown, and 32 languages are coloured, loaded as needed.
- **Todos come from Claude Code's own tools,** TaskCreate and TaskUpdate (what current Claude Code offers), with
  TodoWrite as a fallback. Glade has no todo tool of its own. Subagents' todo calls are ignored.
- **The design's "waiting" todo** ("Will ask you before deleting anything") has a look but nothing sets it, since
  Claude Code has no such state. Open question: should Glade add a convention for it?
- **Artifacts:** a file must exist when it's declared; declaring the same file again renames it. The age is the file's
  modified time, and lines are counted up to 8 MB. Copy shows no "Copied" toast, as the design shows none.
- **Subagents have no Queued state.** The SDK starts subagents straight away, so the design's queued row can't happen.
  They're ordered running, then done, then failed, and the tab counts all of them. What a subagent says is logged as
  notes under its call. Stopping the turn marks subagents still running as Failed.
- **Narrow windows:** the header's title and timing truncate, with tooltips, and the objective and status clamp to two
  lines (one under 900px tall).
- **Rename** is inline in the task list row (F2); clicking away saves, unless the title is blank, which is refused.
- **Delete** confirms with 'Delete "title"?': the task's chat, tool log and queue are removed and its agent stopped;
  files on disk aren't touched. It has no shortcut, and the next task is selected after. Nothing in the app opens the
  confirmation yet; the task context menu (P6-03) will.
- **Verification notes:** `09-todos` and `10-artifacts` match apart from sample data. `08-open-file` matches, but the
  design highlights lines 8–9 of the open file, while `show_file` marks a single line. `11-subagents` differs where
  the design shows a queued subagent (see above) and its first row already expanded. The design's Todos "waiting"
  item can't be produced. Delete has unit tests but no e2e spec, since nothing in the UI reaches it yet. In a narrow
  window the right panel's tab strip is cut off at its edge: the Subagents tab is clipped or hidden, with no overflow.
