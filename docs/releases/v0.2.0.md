Glade 0.2.0 is about running many tasks at once and knowing which one needs you.

## What's new

- **Parallel tasks.** Start as many tasks as you like. Each runs its own agent session, with its own chat and tool log.
  Switching tasks never interrupts one that's working, and stopping one leaves the others alone.
- **Message queue.** Send while the agent works and your message waits in a numbered queue above the input. Edit it in
  place (↑ in an empty input edits the last one) or remove it. Queued messages survive a restart and go to the agent,
  in order, as soon as it finishes its current step.
- **Turn summary.** Under each finished reply: how long the turn took, and how many files it changed with lines added
  and removed.
- **Unread and Needs you.** A reply in a task you aren't looking at makes it unread: a bold title and a blue dot.
  The All, Needs you and Unread chips at the top of the sidebar count and filter tasks. Opening a task reads it, and ⌘⇧U
  marks it unread again. All of it holds across restarts.
- **Notifications.** A reply in a task you aren't viewing sends a macOS notification with the task's title and the
  start of the reply. Click it to open that task.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.2.0-arm64.dmg` below, open it and drag Glade to Applications. Your tasks from 0.1.0
  carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.

Not in this release: the terminal and plugin panels, search, and the other right-panel tabs. Those come in later
phases.

## Calls made without Jared (please review)

- **Release builds** are Apple silicon only, because the Agent SDK bundles a Claude binary per platform. They're
  ad-hoc signed until Developer ID signing lands (L-04), so macOS offers right-click → Open instead of calling the app
  damaged.
- **Turn summary** shows only on turns that end with a reply, not on stopped or failed ones. It's stored with the
  agent's reply, and the duration is the SDK's own `duration_ms`. So a turn that resumed after a restart shows only
  the time since the restart.
- **Unread** is set when the agent's final reply lands in a task you haven't selected, and selecting the task clears
  it. Changing only the unread flag doesn't count as an update, so it doesn't move the task in the list.
- **Needs you** means an active task that is waiting on you or errored, and has run at least once (it has a session or
  its first turn failed). Brand-new tasks don't count.
- **Filters** keep the Pinned, Active and Done sections and filter the rows inside them. The chosen filter is
  remembered.
- **Queue delivery** happens once every top-level tool call in the current step has its result, or when the turn ends.
  Delivered messages appear inside the running turn.
- **A stopped or failed turn keeps the queue.** Your next message sends the queued ones and the new one together.
- **Known edge case:** a message already handed to the agent isn't taken back by Stop.
- **Queue editing** is inline (↵ saves, Esc cancels). The pencil icon is Font Awesome's solid pen, since there's no
  free outline one; it reads heavier than the design's.
- **Notifications** are plain text, the first ~100 characters cut at a word break. There's one per final reply, even
  in a task that's already unread. The phase goal says "any agent message", but only final replies notify, not
  interim text. The design's notification has Open task and Reply buttons; ours has neither (clicking opens the task).
  They've only been tested against a fake notifier, not checked by eye on a real Mac.
- **Verification notes:** the sidebar and queue match `02-agent-working` and `04-needs-you` apart from small spacing
  (the workspace header sits a little lower) and the heavier queue icons. Tasks are sorted by recency, so the Active
  order differs from the mockup's, and Done starts collapsed. Delivering several queued messages in order is covered by
  unit tests; the end-to-end test delivers one after removing the other.
