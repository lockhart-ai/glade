Glade 0.14.0 puts what's in flight in the macOS menu bar, adds a Changes tab with the commits a task made, and takes
more of what it shows straight from the Claude Agent SDK: the models and effort levels, subagent summaries, the
compaction threshold, startup errors and your account.

## The chat and window

- **The chat is clipped under the header and the input bar.** It scrolls up under the header card and down under the
  input bar, cut off halfway under each, so it never shows around their corners, and it sits slightly inside their
  edges.
- **Question cards wrap their choices.** A question with many options lays them out in rows, up to three to a row,
  instead of squeezing them onto one; long words and paths stay inside their card.
- **Questions open with a reply.** The agent can answer what you said at the top of a question card before it asks,
  so a card no longer seems to jump straight to conclusions.
- **The pin and Mark done match** in the task header: both solid, borderless icons.

## Tasks and the sidebar

- **A third line on task rows.** A task's todo progress, running subagents and live watchers sit on a compact line
  under its status, each an icon and a count, only while there's something to show. The title and status lines get
  the row's full width back.

## The right panel

- **Changes** (⌘⌥7) is a new tab listing the commits the task and its subagents made, newest first, with the branch,
  the lines changed and which subagent made each. A commit opens to its files, and a file opens in Files, even after
  its worktree is gone.
- **Artifacts** are compact rows with thumbnails, grouped by date (Today, Yesterday, This week and so on), each group
  folding. An artifact you or the agent edit moves back to the top, live.
- **Todos** are ordered by state: what's active first, then what's done (most recent first, each with when it
  finished), then what's not started. Done items have a filled teal check and items not started a hollow ring, so
  they're easy to tell apart.
- **Subagents** show a live one-line summary of what each running subagent is doing, and any background work a
  subagent started is listed under it, not in the task's Watchers.
- **Watchers** no longer lists ordinary shell commands that simply took a few seconds, and old rows stuck on
  "running" are cleared.

## The agent and the SDK

- **Stop ends only the turn.** Background subagents and watchers keep running; each still has its own Stop.
- **The model and effort pickers come from the SDK**, so they list what your login offers, including Extra high
  effort where a model has it, and no effort picker for a model without one.
- **The context meter follows your Claude Code settings** for auto-compact, and a Compact row opens to the summary
  the compaction left.
- **Startup errors say why.** When Claude Code can't start a session, the error card says why in plain words, and
  what the Claude process printed goes to the log.
- **Complete final replies.** The agent is told that its last message of a turn is the one you see, so it ends each
  turn with a full answer rather than a closing line after follow-up work. Tasks already running get this once.

## The menu bar

- **Glade has a menu bar icon.** It shows how many tasks need you and pulses while an agent works. Its popover lists
  what needs you, what's working and the latest notifications; a row opens Glade on that task. Turn it off in
  Settings › General.

## Settings, account and usage

- **Settings › General shows your account:** the account, organisation and plan your tasks use, and how Glade is
  signed in.
- **A quiet note before the usage limit.** When you've used most of a usage window, a note says how much and when it
  resets, before anything pauses.

## Tooling and process

- Design renders no longer hang, and fail fast with a clear message when they stall.
- Pull requests carry labelled before and after screenshots, update the docs they touch, and open as drafts until
  their media is published.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.14.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.13.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- The two chat clipping issues were fixed together in one PR. The chat is inset 8px from the header and input cards
  and clipped halfway under each. The chat column's minimum width grew from 380 to 396px, so two question options
  still fit side by side in the smallest window. (#268, #270)
- Question choices are cards at least 160px wide, at most three to a row. A very long word breaks anywhere rather
  than being cut short with "…". (#269)
- The menu bar popover orders Needs you by most recent change and Working by the longest-running turn. Paused tasks
  show under Working. The last 20 notifications are kept, and Recent lists only notifications Glade actually sent.
  The popover is a macOS panel, so opening it doesn't bring the main window forward. (#271)
- Stop now ends only the turn; background subagents and their work keep running. This was checked against the real
  SDK. (#276)
- The model and effort pickers are built from the SDK's list. That adds "Extra high" effort where a model supports it,
  and there's no effort picker for a model without effort levels. (#277)
- Subagent summaries come from the SDK, about every 30 seconds. (#278)
- The auto-compact threshold now comes from the SDK, so it honours your Claude Code settings. (#279)
- Each of the SDK's startup-failure reasons gets one plain message. The Claude process's error output is logged, at
  most 20 lines per 10 seconds per task. (#280)
- Settings › General shows the account. The design's single Settings screen was split into General and Agent
  screens. A calm note shows when the SDK warns that the usage limit is near. (#281)
- Todos are ordered active first, then completed (newest first, with finish times worked out from the tool log), then
  not started. Completed items get a filled teal check; items not started get a hollow ring. (#282, #308)
- The pin and Mark done are both solid, borderless icons. (#289)
- The sidebar's third row shows todo progress, running subagents and watchers, in that order, and each only when its
  count isn't zero. (#290)
- Foreground shell commands are no longer counted as watchers. A finished subagent's background work runs on until it
  ends (the SDK keeps it going); only a stopped subagent's work is closed. Old stuck rows are removed. (#291)
- The ask preamble is up to 2,000 characters. It isn't included in search results or sent to plugins. (#298)
- The final-reply rule was added to the system prompt, and is delivered once to tasks that were already running.
  (#301)
- The Changes tab is view-only. It lists the commits the task and its subagents made, with no GitHub lookups. (#275)
- Artifacts: weeks start on Monday. Ages read "8m" for today, the clock time for yesterday, and "Sep 21" before
  that. An artifact not yet re-checked on disk uses the time it was declared. Ordering follows each file's
  last-modified time, updated live. (#307)
- Deferred: the traffic-light layout (mockups made, parked by Jared), and signing and notarisation (L-04).
