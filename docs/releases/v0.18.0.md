Glade 0.18.0 fixes a terminal tab that could freeze the whole app behind an invisible error dialog, keeps a long-running
`ask` waiting for weeks instead of timing out after about 28 hours, takes a task's status, true dates and its own id
through the control API, has the Artifacts image viewer step only through the images its list actually shows, reloads a
plugin when its build changes on disk, and lets the model — and the control API — update and remove artifacts, not just
add them.

## Terminal

- **A terminal tab running short commands in a loop could freeze Glade behind an error dialog you'd never see.**
  node-pty briefly reports no foreground process the instant one program ends and before the shell takes the terminal
  back; a tab looping over commands hit that gap often enough to throw, and the uncaught exception put up Electron's
  own alert, which blocked the whole app until someone found and dismissed it. Glade now keeps what the tab last
  showed while it can't say what's running, instead of throwing. (#376)

## Asking

- **`ask` no longer times out after about 28 hours.** Claude Code bounds every MCP tool call by default; Glade's own
  `glade` server now asks for the longest bound Claude Code allows, about 24.8 days, so a question can wait out a long
  weekend, not just overnight. A card Glade quits on still waits with no bound at all once the app relaunches.
  (#386)

## Control API

- **`create_task` and `update_task` take a task's status, true dates and its own id.** A backfill can now set a task
  done, dated when it really happened, in one call, and correct it afterwards; `update_task` also takes `externalId`,
  so a task's id can follow its notes folder when it moves. Every date the API takes reads the same way: a date alone
  means that day at local noon, wherever Glade runs, so a task never lands a day early or late; a date and time needs
  its offset or `Z` to mean an exact instant. `docs/control-api.md` now has a table of which patch fields move a task
  in the sidebar and which keep its place. (#388)

## Artifacts

- **The image viewer steps only through the images the Artifacts tab actually shows.** It used to include every image
  artifact of the task, even ones tucked inside a folded "Last week" or older group the tab hadn't opened; now it's
  built from the same open groups the tab shows, undeclared images beside them included, so ← and → never turn up
  something the list didn't. (#387)
- **The model can rename, repoint or remove an artifact, not just add one.** `update_artifact` (`path`, `title?`,
  `newPath?`) renames it and/or points it at a file that's moved, keeping its place; `remove_artifact` (`path`) takes
  it off the list without touching the file. Both show up in the Artifacts tab right away. The control API's
  `update_task` gets the same through `patch.updateArtifacts` and `patch.removeArtifacts`, applied removals, then
  changes, then additions, all or nothing. (#389)

## Plugins

- **A running plugin reloads when its build changes on disk.** Reinstalling over a plugin that's running used to
  leave its view stale until Glade restarted; now the next rescan (opening Settings › Plugins) reloads it if its
  manifest version or entry file changed, keeping its place in the bottom bar and its saved panel width. A **Reload**
  button on each row reloads it right away, without waiting for a rescan. (#390)

## Under the hood

- Fixed the import performance test's flaky budget (#377): the reference now prepares a statement per row, as the
  app's own repositories do, instead of once for the whole run, and the budget is tighter and less sensitive to how
  busy the machine is.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.18.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and
  tasks from 0.17.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac;
  attach them to a bug report if you like (`docs/logs.md` says what's in them).

## Calls made without Jared (please review)

- `ask`'s new ceiling is still a ceiling — about 24.8 days, the longest Claude Code allows — not truly unbounded:
  Claude Code has no "never" setting for an MCP tool call. (#386)
- A date and time given without its offset or `Z` is still refused rather than guessed at (assumed local, say):
  ambiguous input stays an error instead of a guess. (#388)
- A date alone means local noon, not local midnight or UTC midnight: a call on what reads most naturally as "that
  day" across time zones. (#388)
- `externalId` can be set or replaced but not cleared back to null, unlike `handoff`, which takes `null` to clear it.
  (#388)
- The image viewer now skips a folded date group's images until it's opened — a reversal of 0.17.0's call that a
  missing image artifact stays in the ← → sequence rather than being skipped over (#373); here, matching what the
  list actually shows won out over never skipping anything. (#387)
- `add_artifact` still renames an artifact on a second declare at the same path, rather than taking on
  `update_artifact`'s semantics, so existing callers keep working. (#389)
- A plugin's rebuild is detected by its manifest version and its entry file's mtime and size, not a content hash:
  fast, but a rebuild that happens to land on the same size and mtime would go unnoticed until the next real change.
  (#390)
- The Reload button always reloads, whether or not Glade thinks the plugin changed, so it stays useful as a plain
  "reload this view" while iterating on a build. (#390)
