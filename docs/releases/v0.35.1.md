v0.35.1 follows up 0.35.0 the same day: issues and PRs linked to a todo now show their state, checks and comments, GitHub notices move out of the chat into the agent's log, and tasks carried over an update learn what changed in Glade's prompt and tools.

## What a user notices

- **A linked issue or PR shows its state, checks and comments in the Todos tab (#683, PR #704).** An open todo's issue and PR rows carry a coloured second line: Open, Draft, Merge queue, Merged or Closed; checks running, passed or failing with counts; Approved or Changes requested; comments. A closed todo puts the state on its link-count line, or, with more than two links, one count per state ("1 failing · 2 open · 1 merged"). States show at once after a relaunch, before the next poll.
- **GitHub notices go to the agent's log, not the chat (#715, PR #716).** The agent still gets each notice as its prompt; the chat no longer shows it as a blue message from you. Main's log in the Agents tab shows a GitHub row with what changed, at the time it arrived.
- **A todo link scrolls that todo to the top of the list (#713, PR #714),** opened, on the first click.
- **Tasks carried over an update learn what changed (#708, PR #711; #709, PR #712).** A prompt line whose wording changed is sent again once (0.35.0's "set a todo waiting" never reached older tasks), and a task is told once when one of Glade's own tools has changed since it last saw it, naming the tool and what it takes now. Claude Code keeps a carried-over session's first view of its tools until the conversation compacts, and there's no supported way to make it reload them, so this note is how the task learns.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Install:** download `Glade-0.35.1-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.35.0 carry over.
- **Database:** two migrations, forward only: 0081 (a fingerprint of the prompt lines each session has seen) and 0082 (the Glade tools each session has seen).
- **Signing:** the same self-signed certificate as 0.34.1 and 0.35.0, so macOS permission grants carry over.
- **Logs:** `~/Library/Logs/glade/main.log`.
