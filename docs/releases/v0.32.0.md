v0.32.0 fixes session resumption for OpenRouter-only tasks, login renewal for dispatched children, stopping while a permission card waits, the limit-switch note surviving a relaunch, and plugins seeing a subagent stop.

## What a user notices

- **A session that has only run on an OpenRouter model resumes again (#639, PR #644).** v0.31.1 broke this: resuming such a session (a dispatched child on an OpenRouter model, or very likely a task on one after a relaunch) failed with "Session not found". The fix in v0.31.1 for switched tasks started merging a local session file into Glade's saved history on every OpenRouter start, and failed when there was no such file. Now a missing file means there is nothing to merge, and the saved history is used.
- **A resumed dispatched child on a Claude model keeps a login that can renew (#627, PR #643).** The same flaw v0.31.1 fixed for a task's own session: a child resumed on a Claude model ran on a copy of the login without its refresh token. It now takes the same path as a task's own session.
- **Stop works while a permission card waits (#511, PR #642).** The Stop button shows beside Send, and ⌘. stops, while a permission card waits for an answer; stopping withdraws the card.
- **The limit-switch note survives a relaunch (#564, PR #641).** When a task stopped by a usage limit is switched to another model, Glade tells the agent which background work it stopped. That note is now kept in the database, so a relaunch before the next prompt no longer loses it.
- **Plugins see a subagent stop when a refusal fallback removes it (#503, PR #640).** Nekomata no longer keeps drawing such a kitten as running.

## Under the hood

- Migration 0077 adds a small table for the limit-switch note. Migrations only go forward: a database opened by 0.32 can't be opened by 0.31.
- Design screens 23 and 24 now show the Stop button while a permission card waits (#642).
- The README's Nekomata picture shows the 32bit style (#632).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.32.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.31.1 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).
