v0.34.0 works on the Files tab: files open on their preview, the Markdown preview reads on a lifted surface, and a file open in Glade now follows what happens to it on disk. It also keeps the HTML preview inside its box when the layout around it changes.

## What a user notices

- **A file you're only viewing reloads quietly when it changes on disk (#646, PR #666).** Glade watches each file open in the Files tab, so a change from outside the agent (a script, git, another editor) shows up without action: an editor with no unsaved edits takes the new text quietly, and Markdown and HTML previews reload too. A file with unsaved edits keeps them and shows the existing "This file changed on disk." bar with Reload and Keep mine.
- **A file reopened shows what is on disk now (#658, PR #663).** A file rewritten on disk while its tab was closed used to show its old contents when reopened in the HTML preview. The preview now loads fresh from disk on reopen; the source view and the Markdown preview already re-read the file when they open.
- **The HTML preview stays inside its box when the layout around it changes (#656, PR #664).** A burst of resizes (dragging the right panel's splitter, the bottom panel sliding open) could complete out of order and leave the preview drawn over the input bar's Send button and the bottom panel. It now places in the order the asks came.
- **A Markdown or HTML file opens on its preview (#657, PR #665).** The preview is what you usually want to see; Source is one switch away. A line the agent shows still opens on Source, so the line can be marked.
- **The Markdown preview reads on a lifted surface (#659, PR #662).** A lighter dark surface (#2C3040) with body text at #F0F2F8, line height 1.7 and a reading column about 70 characters wide. This was the owner's pick of four mockups, and only the Markdown preview lifts; the HTML preview and the source view stay as they were.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.34.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.33.0 carry over.
- **Database:** no migrations in this release; your database opens as it is.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).
