Glade 0.6.0 is about finding and organising: search across every task in a workspace, and a right-click menu on
anything you can act on, including the task menu that finally lets you delete a task.

## What's new

- **Search.** Type in the sidebar's search field (⌘F from anywhere) and the task list gives way to results as you
  type: titles, objectives, statuses, outcomes and the full chat of every task in the workspace. Each result shows a
  snippet around its best match, with the match marked. Opening one marks the matches in its header and chat, and
  scrolls the chat to the first. Esc, or clearing the field, brings the list back. It keeps up on a workspace with
  hundreds of tasks.
- **Task actions, from a menu.** Right-click a task in the list or in the search results (or press ⇧F10 on it) for
  Open, Pin to top, Rename…, Mark as unread, Mark done, Copy link to task and Delete task…. A done task offers Reopen
  and Copy outcome instead of Mark as unread and Mark done. Delete task… always asks first. The keys from 0.5.0 still
  work (F2 renames, ⌘⇧P pins), and ⌘⇧U marks the selected task unread.
- **Context menus everywhere.** An agent reply: copy it as text or Markdown, quote it in your reply, or show that
  turn's tool calls. A queued message: edit or remove it. A tool call: copy its command or output, or open its file. A
  file tab: close it, the others or all, open it in your editor, reveal it in Finder, or copy its path. An artifact:
  open it, copy its contents or path, reveal it, or remove it from the list. A subagent: expand or copy its log, or
  stop it while it runs. A todo: copy it, or ask the agent about it. Destructive items sit last, in pink.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or
  stores your credentials.
- **Install:** download `Glade-0.6.0-arm64.dmg` below, open it and drag Glade to Applications. Your tasks from 0.5.0
  carry over, and the first launch indexes them for search.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose
  Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings → Privacy & Security). If macOS
  still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.

Not in this release: more than one workspace, Settings, collapsible panels, and the terminal and plugin panels. Those
come in later phases.

## Calls made without Jared (please review)

- **Tested with a scripted agent only.** Search, the task actions and every menu have been exercised against Glade's
  scripted fake agent and sample data in the tests, not a real model.
- **Rename and Delete** work as listed in 0.5.0 (inline rename, refused when blank; 'Delete "title"?', which removes
  the task's chat, tool log and queue, stops its agent and leaves files on disk alone). The task menu is now what
  opens the delete confirmation.
- **Search ranks by the best field,** title first, then objective or status, then chat, with newer tasks first on a
  tie. It doesn't use SQLite's bm25 ranking, which was too slow for one-letter searches on a big workspace. Every word
  you type must match within one field or one message. The search text isn't kept across a relaunch, and there's no
  ⌘P jump-to-task.
- **Opening a search result** scrolls the chat to the first match.
- **Copy link to task** copies a `glade://task/<id>` link, but Glade doesn't open those links yet.
- **Stop subagent** uses the SDK's `stopTask`. It hasn't been tried against the real API.
- **Remove from artifacts** doesn't ask first; the file itself stays.
- **Left out of the menus:** the Todo menu's Mark done myself and Remove (Claude Code rewrites the list, so they
  wouldn't stick), and the terminal pieces (the tool call's Run again in terminal and the terminal tab menu), which
  wait for the terminal in P8.
- **Verification notes:** `07-search` matches apart from sample data; a hyphenated match in a snippet can break across
  lines ("Retry-" / "After"). `12-right-click-task` and `13-context-menus` match apart from the items removed from the
  reference (Reveal folder in Finder on task menus). In a done task's menu, Pin to top and Rename… show no shortcut
  hints, as `docs/context-menus.md` lists them, where the design shows ⌘⇧P and F2. A pinned task's menu says Unpin.
  With no task selected, as on a big seeded workspace, the middle pane is empty.
