0.31.0 adds preview for HTML files, shares the Agents tab's width among active subagents with a list of finished ones, and keeps question card answers across task switches.

## What a user notices

- **Files: Preview for HTML files (#614, PR #623).** An `.html` or `.htm` file in the Files viewer has the same Source / Preview control Markdown has. Preview renders the page in place: its own styles and scripts run, and images and stylesheets beside it in its folder load. The page is shown in a sandbox of its own with no access to Glade, and it is offline: anything it asks for over the network is blocked, with a quiet line saying so. A link you click opens in your browser. The preview follows the file when the agent rewrites it.
- **Agents tab: active subagents share the strip, finished ones are in a list (#617, PR #622).** The strip is Main (its dot only, no pin), then one tab per active subagent sharing the width evenly, then a caret with the number of finished subagents. The caret opens "Finished, newest first", with each name and how long ago it finished. Picking one shows it as a tab after the active ones, with a grey dot, until you choose Main or an active subagent. When there are many active subagents the tabs narrow to a minimum and their names shorten; the full name shows on hover. The old scrolling strip is gone.
- **Question cards keep what you filled in (#615, PR #621).** Options picked, pills, typed answers and "Anything else?" on an unanswered question card are kept when you switch task or workspace and come back, and across a relaunch, the same way the input bar keeps an unsent message. They are cleared when you send the answers.

## Under the hood

- Migration 0076 adds a draft column to the question sets table. Migrations only go forward: a database opened by 0.31 can't be opened by 0.30.
- The HTML preview's page scheme and the plugins' scheme are registered together at start-up; registering them separately would have dropped the plugins' privileges (found and fixed before merge, #623).
- The app's desktop services (clipboard, opening links, Finder) are created once at start-up (#623).
- Older end-to-end tests that drove the scrolling Agents strip now use the caret's list (#622).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.31.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.30.0 carry over.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).
