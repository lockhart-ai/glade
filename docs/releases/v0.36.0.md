v0.36.0 lets tasks message each other, starts faster when tasks were left mid-call, and draws GitHub notices in the agent's log like every other row. The README's and guide's screenshots are current again, and CI no longer asserts timings.

## What a user notices

- **Tasks can message each other (#710, PR #745).** An agent can send a message to another Active task in its workspace with `message_task`. It arrives like a broadcast: it starts the other task's next turn, or waits behind its current one. In the chat it sits on the left in a slate-blue bubble, with a ⇄ chip naming the sending task and that task's title in place of "agent" or "you" (mockup A). The receiving agent can reply the same way. Every task is told about the tool once.
- **Launch no longer stalls on tool calls left running (#701, PR #742).** Marking them interrupted was one database update per call, about 0.6 s on a busy installation; it is one statement now, a few milliseconds. A clean quit also marks running calls, so the next launch has little to do.
- **A GitHub notice in the Agents tab looks like the other rows (#748, PR #749).** A dot, **GitHub** where a tool's name goes, the PR or issue on the same line, the time at the right, and what changed under it; one row per link.
- **The README and the user guide show today's app (#741, PR #743).** 28 of 29 screenshots recaptured; Nekomata's keeps its old picture until its plugin is built here.

## Under the hood

- CI's e2e specs no longer assert timings; the switch-paint and typing measurements are stress specs now (`GLADE_E2E_STRESS=1`), and CLAUDE.md says to run them for hot-path changes (#746, PR #747).

## Running it

- **Install:** download `Glade-0.36.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks carry over.
- **Database:** one migration, forward only: 0083 rebuilds the two message tables to record a task message's sender. On a large database it may take a moment at the first launch.
- **Signing:** the same self-signed certificate as before, so macOS permission grants carry over.
- **Logs:** `~/Library/Logs/glade/main.log`; launch now logs how many leftover tool calls it interrupted and how long that took.
