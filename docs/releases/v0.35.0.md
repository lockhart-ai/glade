v0.35.0 is the Oct 17 night run: Glade now watches the GitHub issues and PRs a task links and tells its agent what changed, agents hear about your usage as they work, todos can wait on you, and the right panel opens on Todos. It also adds image zoom, tick boxes in the Broadcast modal, a Needs you list in the workspace switcher, and links from a reply straight to a todo.

## What a user notices

- **Glade watches a task's linked issues and PRs and tells its agent what changed (#682, PR #700).** Every GitHub issue and PR a task has linked is polled with your `gh` token (read once, kept in memory only; public links fall back to slow unauthenticated polling without it). When one changes state, finishes CI, gets a review or comment, or gets new commits, the task's agent gets one short message, tagged GitHub in the chat, started as its next turn or queued behind the current one. A link stops being watched once it's merged or closed, or its todo is done. Settings › GitHub watching sets the poll interval and which of the four kinds of change wake a task. The first poll after the update is silent: nothing already merged or closed wakes anyone.
- **Agents are told about your usage as they work (#688, PR #697).** Every message an agent is sent carries a short line with the plan's session and weekly usage (and the task's OpenRouter spend, on OpenRouter). Each time usage crosses another step (10% of a window, or $10 of OpenRouter spend, by default), every agent working right then gets a note mid-turn. Settings › Usage notes sets the steps or turns the notes off.
- **A todo can wait on you (#680, PR #696).** An agent can mark a todo as waiting on you: it shows first in the Todos tab, in purple, with a purple count of what waits on you beside the tab's progress.
- **The right panel's tabs read Todos · Agents · Files, and remember their place per task (#686, PR #702; #689, PR #694).** A task with no remembered tab opens on Todos, and each task keeps the tab you last left it on, across relaunches.
- **The Agents tab counts live watchers (#687, PR #703).** Its label adds the eye and count the task's sidebar row shows, while any watcher is live.
- **A reply can link straight to a todo (#684, PR #698).** Agents can write `[text](todo:N)`; clicking it opens Todos, expands that todo and highlights it.
- **Zoom in on images (#685, PR #695).** Pinch, ⌘+ / ⌘− / ⌘0, or a click toggling fit and actual size, in the Files tab's image view and the full-size viewer; drag or scroll to pan.
- **Choose who a broadcast goes to (#675, PR #693).** The Broadcast modal's recipients are tick boxes, everything ticked to start, with tri-state workspace boxes.
- **The workspace switcher lists the tasks that need you (#681, PR #692).** A Needs you section at the top of its menu, across every workspace, newest first.
- **Pinned and Active tasks are ordered by when they were made (#676, PR #677),** so a task no longer jumps up the list when it updates, and you message the one you meant.
- **The window opens sooner at launch (#674, PR #699).** Main creates the window before finishing the rest of its boot, and the chat no longer flashes "What should the agent do?" while a task's history loads.

## Under the hood

- New tasks can no longer set a handoff note through the control API; existing notes keep working (#668, PR #691).
- Local `npm run package` builds stay ad-hoc signed unless `GLADE_SIGN_LOCAL=1` is set, so they never prompt for the keychain (#673, PR #690).
- `docs/conventions.md`: every PR opens with one sentence saying what it does (#678, PR #679).
- The launch-timing measurement lives with the stress specs (`GLADE_E2E_STRESS=1`), as its seed is too heavy for CI (#674).

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code). GitHub watching uses the `gh` CLI's login if you have one.
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.35.0-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.34.1 carry over.
- **Database:** three migrations, forward only: 0078 (usage-note announcements), 0079 (GitHub link watches) and 0080 (a message's source: broadcast or GitHub, replacing the broadcast flag).
- **Signing:** signed with the same self-signed certificate as 0.34.1, so macOS permission grants carry over.
- **First launch:** Glade isn't notarised by Apple yet, so if macOS refuses it, right-click Glade in Applications and choose Open (or Open Anyway in System Settings › Privacy & Security).
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac.
