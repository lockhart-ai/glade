v0.34.1 signs Glade with one certificate, "Glade Self-Signed", so the permissions you give it in macOS stay given when you update. Until now every build was signed ad-hoc, which made each update look like a new app to macOS and lost its grants. Nothing else changes.

## What a user notices

- **Permissions survive updates (#669, PR #670).** Every release is now signed with the same self-signed certificate. After you grant Glade something once in System Settings › Privacy & Security (Full Disk Access, say, so programs run in its terminal can read other apps' data), that grant holds through later updates. This first signed release looks new to macOS one last time, so grant what you need once more after installing it.

## Under the hood

- The release workflow signs with the certificate from the repository's secrets and refuses to publish if they're missing or the app isn't signed with it; it checks the app's designated requirement names the certificate. A local `npm run package` signs with it when the certificate is in your keychain, and falls back to ad-hoc otherwise (PR #670).
- `docs/releasing.md` has a Signing section: the certificate, the two secrets, and what rotating the certificate costs.

## Running it

- **Requirements:** a Mac with Apple silicon, logged in to [Claude Code](https://docs.claude.com/en/docs/claude-code).
- **Auth:** Glade runs on your own Claude Code login (or `ANTHROPIC_API_KEY`, if you have one set). It never asks for or stores your credentials.
- **Install:** download `Glade-0.34.1-arm64.dmg` below, open it and drag Glade to Applications. Your workspaces and tasks from 0.34.0 carry over.
- **Database:** no migrations in this release; your database opens as it is.
- **First launch:** Glade isn't notarised by Apple yet, so the first time, right-click Glade in Applications and choose Open (on newer macOS, if there's no Open button, click Open Anyway in System Settings › Privacy & Security). If macOS still won't open it, run `xattr -dr com.apple.quarantine /Applications/Glade.app` and try again.
- **Permissions:** grant what you need once more after installing this release, and remove any old Glade entries in Privacy & Security first; later updates keep them.
- **Logs:** `~/Library/Logs/glade/main.log`, one JSON line per event, rotated at 5 MB. They stay on your Mac; attach them to a bug report if you like (`docs/logs.md` says what's in them).
