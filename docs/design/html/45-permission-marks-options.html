Tool calls rows · how a permission decision shows

The same ten calls in each option: three you allowed on a card, one you denied with a note, one withdrawn, two allowed by a rule (a workspace grant, a task rule), one the sandbox refused (a credential file), and two with no permission involved (a failed and a successful call). The dot still says only whether the call itself worked; calls inside the workspace root with no rule involved show no mark.

A · Shield glyph Recommended

The card’s own shield marks a permission, so it never reads as success or failure. Filled purple (the waiting-on-you colour): you, on a card. Outline grey: a rule.
