Decisions and open questions

What's settled going into the breakdown, and what still needs an answer.

Decided
Desktop shell: Electron
Agent runtime: Claude Agent SDK (TypeScript)recommended
Runs in Electron's main process. Streams typed events, takes custom tools in-process, resumes sessions.
State in SQLite
Workspaces, tasks, chat, tool log, todos, artifacts, queue, UI state. Reopening after a crash resumes from the database.
Task folders live in .glade/tasks/<task>/
Inside the workspace root. Tasks can refer to each other through these folders.
The task CLAUDE.md is the agent's running notes
Updated as it works. Notes are saved there before compaction, and context resumes from it.
App exposes a tool surface to the model
The model drives the UI through it: status, title, questions, todos, artifacts. MCP or in-process, whichever fits the runtime.
Two task states: Active and Done
Done stays chat-able; a message reopens it. No follow-up tasks.
Workspace = name + root folder
Top level. Tasks run in the root. Switcher in the sidebar and the menu bar.
Compaction
Automatic at 99% (configurable), manual from the context meter or ⌘⇧K.
Permissions default to Allow all
No per-call review for now.
Terminal is global; settings are a modal
Chat shows final replies only
Preamble goes to the tool log.
Notifications are native OS notifications
Sent for any agent message in a task you're not viewing, even while Glade is focused. Task name + the start of the message. Sound off. Focus and Do Not Disturb are left to the OS.

Model ↔ app surface (proposed)
set_titletool
Name the task from the first message.
set_objectivetool
Distil the objective from the first message.
set_statustool
Rewrite the status summary as work moves.
asktool
Rich question card: choices, pills, sketches, free text. Blocks until answered.
todostool
Write and check off the task's todo list (or map the SDK's own todo tool).
add_artifacttool
Declare a file as a deliverable of the task.
show_filetool
Open a file in the Files tab for the user.
From SDK events, not tools
Tool calls and preamble, subagents, files touched, context usage, compaction, errors.
Plain file edits
The agent keeps its notes by editing the task's CLAUDE.md directly.
