The life of one task

Everything lives in a workspace: a name and a root folder. Inside it, one task is one agent session with one objective. It is either active or done — nothing in between — and it can move back and forth.

you mark it done
you send a message: it reopens
Starts here
Active

Created with an objective and immediately live. Whether the agent is mid-turn or waiting on you is just what's happening in the conversation — not a separate state.

Resting
Done

Finished. The last status summary becomes the outcome. It stays open to chat: send a message and it reopens.
